
#### The skill categories listed below will be used in this course to guide you through the expected skills that you will acquire after gaining knowledge and experience during this class. 

#### This is a guide, so that you formally understand how your class is designed and configured. You can use this as a reference when working on your labs throughout the semester.

| Code    | Description                                               |                                                                                                                |
| ------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| S-01  | Skill in setting up, configuring, and navigating a cloud based product to use flow charts.
| S-02 | Skill setting up, configuring, navigating and using Github.com source code repositories.
| S-03 | Skill in communicating effectively with stakeholders via email, presentations and other communication mediums.
|S-04| Skill in writing code in a programming language that results in a mathematical calculation, algorithm or other type of applied mathematics for critical thinking.
|S-05| Skill in writing a program that requires correctly formatted output as specified by a requirement from a stakeholder. Including printing to the console using different formatting techniques.
|S-06| Skill collaborating with teammates and stakeholders using a digital medium, where opinons are shared, discussed and validated among peers. This also improves debate skills when consensus is not the outcome.
|S-07| Skill in using functions in a programming language. This can include both built-in(canned) and user-defined functions along with optional arguments for built-in functions.
|S-08| Skill in passing arguments to a user-defined function and using the arguments to generate and/or validate the information retured from the function(s).
|S-09| Skill in validating user input/output to ensure accuracy.
|S-10| Skill in applying loops in a programming language to accomplish a specific goal that meets a written requirement.
|S-11| Skill in string parsing/slicingtion and manipulation.
|S-12| Skill in troubleshooting and debuggin a program and identifying how to fix the problems.
|S-13| Skill in writing structured code that is easily maintainable over time.
|S-14| Skill in best practice naming conventions for program names and compiling/executing a program using command line(CLI) tools.
|S-15| Skill in reading and understanding a business requirements document, applying understanding of the requirements, presenting findings, asking stakeholder clarifying questions.
|S-16| Skill in prompting users for required input and using the input captured for futher processing in a program.
|S-17| Skill in structuring and iterating through compound data structures (e.g., lists of dictionaries, nested arrays).
|S-18| Skill in reading from and writing to different types of files(e.g. .txt, .csv, .log) using a programming language.
|S-19| Skill using nested loops in a program to generate, validate and/or render accurate information provided from a written requirement.
|S-20| Skill using local and/or global variables in a programming language.
