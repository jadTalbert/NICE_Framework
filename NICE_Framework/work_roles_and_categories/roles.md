
#### The Job categories listed below will be used in this course to guide you through the roles that you will experience in real-World scenarios. 

#### This is a guide, so that you formally understand how your class is designed and configured. You can use this as a reference when working on your labs throughout the semester.


| Code | Job Title | Description |
| :--- | :--- | :--- |
| DEV-1 | Junior Python Developer | Builds foundational scripts, flow charts, implements basic programmatic logic, processes file inputs, and creates structured functions. Explains in detail to their team and team lead how code works. May use AI as a tool to assist in troubleshooting under guidance from their team lead. |
| SA-1 | Junior Python Security Analyst | Reviews code for vulnerabilities and provides feedback to the developers and the team responsible for fixing the security issues. |
| QA-1 | Quality Control Analyst | Reviews code for accuracy and provides feedback to the developers and the team responsible for fixing any code defects. |
