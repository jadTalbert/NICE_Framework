# Course Work Roles Master Catalog

#### The Job categories listed below will be used in this course to guide you through the roles that you will experience in real-World scenarios. 

#### This is a guide, so that you formally understand how your class is designed and configured. You can use this as a reference when working on your labs throughout the semester.

| Code | Title / Role Name | Description |
| :--- | :--- | :--- |
| <nobr>`DEV-1`</nobr> | Junior Developer | Builds foundational scripts, flow charts, implements basic programmatic logic, processes file inputs, and creates structured functions. Explains in detail to their team and team lead how code works. May use AI as a tool to assist in troubleshooting under guidance from their team lead. |
| <nobr>`SA-1`</nobr> | Junior Security Analyst | Reviews code for vulnerabilities and provides feedback to the developers and the team responsible for fixing the security issues. |
| <nobr>`QA-1`</nobr> | Junior Quality Assurance Analyst | Reviews code for accuracy and provides feedback to the developers and the team responsible for fixing any code defects. |
| <nobr>`JRT-1`</nobr> | Junior Red Team Security Analyst | Reviews system and application vulnerabilities using RoE(Rules of Engagement) Anatomy and the Ethical Hacking Lifecycle. Including Reconnaissance(OSINT), Scanning and Enumeration, Exploitation, Reporting and Remediation |
| <nobr>`JRT-2`</nobr> | Junior Blue Team Security Analyst | Reviews system and application vulnerabilities, monitors/observes potential threats vectors and active attacks and defends against Red Team attckers and other bad actors |
| <nobr>`BISA-1`</nobr> | Business Information Systems Analyst | Evaluates enterprise software integrations, conducts multi-model generative AI stress-testing and governance audits, authors structured prompt engineering frameworks, and coordinates between business stakeholders and technical automation pipelines. |
